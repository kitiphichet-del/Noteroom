# Live Lecture Notes for Android

แอปจดบันทึกคำบรรยายจากเสียงเป็นข้อความแบบสด โดยใช้ Android `SpeechRecognizer` และ `onPartialResults` เพื่อแสดงข้อความระหว่างพูด

## Version 1.2.0
- **Continuous Transcription:** ข้อความสะสมต่อเนื่องจนกว่าผู้ใช้จะกดหยุดเอง\n- ระบบต่อรอบ SpeechRecognizer ให้อัตโนมัติและมี watchdog ช่วยกู้เมื่อบริการเสียงค้าง\n- เก็บ partial ล่าสุดก่อนต่อรอบ เพื่อลดอาการคำท้ายหาย\n- แสดงข้อความแบบสดระหว่างพูด (partial results)
- หน่วงการแสดงผล 0 / 0.25 / 0.5 วินาที
- ฟังต่ออัตโนมัติเมื่อระบบแบ่งช่วงเสียง
- ภาษาไทยเป็นค่าเริ่มต้น พร้อม English และจีนตัวย่อ
- หมุนหน้าจอแล้ว Activity ไม่ถูกสร้างใหม่
- เก็บ draft อัตโนมัติ
- **เมื่อกดหยุด ระบบบันทึกการจดลงไฟล์ .txt ภายในคลังของแอปอัตโนมัติ**
- ปุ่ม **บันทึก** สำหรับบันทึก/อัปเดตไฟล์ปัจจุบัน
- ปุ่ม **บันทึกใหม่** เพื่อเริ่มโน้ตคนละไฟล์
- หน้า **คลังบันทึก** แสดงรายการไฟล์ทั้งหมด
- แต่ละรายการสามารถ **เปิด / ส่งออก / ลบ** แยกกันได้
- มีหน้าต่างยืนยันก่อนลบไฟล์
- ส่งออกเป็น `.txt` ไปยังพื้นที่ที่ผู้ใช้เลือกได้
- เปิดหน้าจอค้างระหว่างกำลังจดบรรยาย

## การเก็บไฟล์
ไฟล์ใน “คลังบันทึก” เก็บอยู่ในพื้นที่ private storage ของแอป จึงไม่ต้องขอสิทธิ์ Storage เพิ่ม และแอปสามารถลบรายการที่ผู้ใช้เลือกได้โดยตรง

เมื่อต้องการนำไฟล์ออกจากแอป ให้กด **ส่งออก** ในรายการนั้น หรือกด **ส่งออก .txt** จากหน้าหลัก

## ข้อจำกัด
ผลลัพธ์สดเป็น hypothesis ของระบบรู้จำเสียง คำท้าย ๆ อาจเปลี่ยนได้เมื่อระบบได้รับบริบทเพิ่มขึ้น และความแม่นยำ/โหมดออฟไลน์ขึ้นกับ Speech Recognition Service และ language pack ของโทรศัพท์
